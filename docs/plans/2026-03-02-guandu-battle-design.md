# 官渡之战安排工具设计文档

## 项目概述

为《三国·冰河时代》游戏设计的官渡之战玩家安排工具，帮助联盟指挥快速合理地分配玩家到各个建筑点位，最大化积分获取效率，提升获胜概率。

## 需求分析

### 核心需求
- 还原官渡之战的地图布局和建筑位置
- 支持玩家按属性和分工分配到不同建筑
- 显示战役阶段和建筑开放时间
- 提供Excel导入导出功能
- 支持团队分配和忽略功能

### 功能需求清单

| 功能模块 | 具体功能 | 优先级 |
|---------|---------|--------|
| 地图渲染 | 还原官渡之战垂直分布地图 | 高 |
| 建筑显示 | 显示建筑位置、开放时间、作用 | 高 |
| 阶段管理 | 时间轴、阶段切换、事件提醒 | 高 |
| 玩家分配 | 按属性/分工分配、团队分配 | 高 |
| 数据导入 | Excel导入玩家数据 | 高 |
| 数据导出 | 导出分配结果到Excel | 高 |
| 忽略功能 | 支持忽略特定玩家 | 中 |
| 统计信息 | 显示总人数、分配情况等统计 | 中 |
| 响应式设计 | 适配不同屏幕尺寸 | 中 |

### 前端架构
- **React + TypeScript**：使用现代化的前端框架

## 功能设计

### 1. 地图布局与建筑显示
- **地图结构**：垂直分布的地图，从上到下依次为乌巢、兵器坊、大粮仓、官渡、霹雳车、工匠坊
- **对称布局**：左右两侧对称分布小粮仓
- **建筑标注**：使用不同颜色和图标区分建筑类型
- **开放状态**：根据时间显示建筑的开放/关闭状态

### 2. 阶段管理
- **时间轴**：显示40分钟战役时间轴
- **阶段切换**：自动或手动切换三个阶段
- **事件提醒**：关键事件（如辎重车刷新）的时间提醒
- **时间同步**：与本地时间同步，显示实时战役进程

### 3. 玩家分配规则
- **属性排序**：支持四维和、六维和、骑弓维、输出、坦度等属性排序
- **分工分配**：根据大车头、二车头、中战、低战/辅助、替补等分工固定分配位置
- **团队分配**：支持军团1、军团2的团队分配
- **建筑优先级**：根据建筑开放时间和积分效率智能分配人员

### 4. 数据管理
- **Excel导入**：支持导入包含玩家属性数据的Excel文件
- **数据验证**：验证导入数据的完整性和正确性
- **本地存储**：保存用户配置和历史记录
- **导出功能**：导出分配结果到Excel文件
